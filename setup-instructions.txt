STEP 3 — Create a GitHub repository and push
----------------------------------------------
1. Go to https://github.com/new
2. Create a new repository (e.g., "dental-arch-analysis")
   - Set it to PUBLIC (required for free GitHub Pages)
   - Do NOT initialize with README (we already have one)
3. Push your local repo:
   git remote add origin https://github.com/YOUR_USERNAME/dental-arch-analysis.git
   git branch -M main
   git push -u origin main


STEP 4 — Enable GitHub Pages
------------------------------
1. Go to your GitHub repository
2. Click "Settings" tab
3. Click "Pages" in the left sidebar
4. Under "Source", select:
   - Branch: main
   - Folder: / (root)
5. Click "Save"
6. Wait 1–3 minutes, then visit:
   https://YOUR_USERNAME.github.io/dental-arch-analysis/

The site will show login.html automatically.

NOTES ON GITHUB PAGES
------------------------
- GitHub Pages serves static files only. No server-side code.
- The password protection is client-side (SHA-256 hash). It prevents
  casual access but is not cryptographically secure against determined users.
  This is appropriate for academic demo/showcase purposes.
- File size limit: 100 MB per file, 1 GB total repo.
  Your STL files (~10–16 MB each) are within limits.
- After pushing large STL files, GitHub may take a few minutes to process.
- If the site doesn't update after a push, do a hard refresh (Ctrl+Shift+R).


TROUBLESHOOTING
-----------------
Problem: Login works but data doesn't load
  → Make sure you are serving via a web server, not file://
  → GitHub Pages serves via HTTP, so this will work there.
  → For local testing: use VS Code Live Server, or run:
     python3 -m http.server 8000
     Then visit: http://localhost:8000/

Problem: 3D STL model doesn't load
  → Check that Dataset/ folder exists inside website/
  → Check that STL filename matches exactly: AnyConv.com__[MODELID]_upper.stl
  → Open browser DevTools (F12) → Console for error details

Problem: GitHub Pages shows 404
  → Ensure Pages is enabled in repo Settings → Pages
  → Ensure the source branch is "main" and folder is "/"
  → Wait 2–5 minutes after enabling, then try again
